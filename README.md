# Laya Local Decisions

Windows에서 Laya 모델의 로컬 분류 동작을 공개 합성 자료로 검증하는 패키지입니다.

**현재 상태는 HOLD입니다. 회사 자료 입력, 업무 사용, 사내 배포 및 공개 출시를 승인한 버전이 아닙니다. 실행기 변경의 빌드와 격리 통합 검증이 완료되지 않았습니다.**

## 제공하는 범위

고정된 공개 파일을 내려받는 준비 단계와 오프라인 설치·무결성 확인·합성 실행 단계를 분리합니다. 모델과 의존성은 명세에 고정합니다. 외부 추론 API로 전환하는 기능은 제공하지 않습니다.

`evaluate`는 해시가 고정된 `tests/synthetic-ko.json`만 사용합니다. 입력 문서, 사용자 질문, 회사 분류 기준을 받는 CLI/API는 제공하지 않습니다. `predict`를 비롯한 지원하지 않는 모드는 파일 처리 전에 거부합니다. 합성 모드의 경로 인수는 입력 파일이 아니라 새로운 결과 파일의 이름을 정하는 용도입니다. 이미 존재하는 입력 또는 결과 파일은 보존하고 거부합니다.

실행기 소스에는 네트워크 capability가 없는 AppContainer, 실행 전 설치 무결성 검사, 자식 프로세스 수 제한, 상속 핸들 차단, 허용 목록 기반 환경 변수가 구현되어 있습니다. 격리 구성이 실패하면 일반 프로세스로 재시도하지 않습니다. 이 구현의 통합 검증은 아직 완료되지 않았으므로 소스 구현을 보안 인증으로 해석하지 않습니다.

Python 감사 훅은 모델 라이브러리보다 먼저 설치합니다. 감사 훅과 오프라인 환경 변수는 보조 수단이며 네이티브 코드, DNS 중계, 운영체제 서비스 및 전체 외부 통신 경계의 차단 증명이 아닙니다.

## 문서와 설치 자료

[설치 안내](docs/INSTALL.ko.md)에서 준비·반입·검증 순서를 설명합니다. [보안 상태와 인수 조건](docs/SECURITY-STATUS.ko.md)은 지원 범위와 남은 검증을 구분합니다. [토큰 절약 가이드북](docs/TOKEN-PLAYBOOK.ko.md)과 [PDF](docs/TOKEN-PLAYBOOK.ko.pdf)는 규칙·검색·캐시·단계별 토큰 계산과 품질 평가를 설명합니다. [과거 사례 조사](docs/GUIDE.ko.md)도 보존합니다. 실제 실행은 위의 지원 범위를 따릅니다.

모델 원본은 `model-manifest.json`, 준비 사본은 `prepared-model-manifest.json`, 의존성은 `dependency-lock.json`으로 고정합니다. 라이선스와 배포 검토 항목은 [NOTICE.md](NOTICE.md)를 확인합니다.

설치는 승인된 Python 3.12 x64와 Windows의 .NET Framework C# 컴파일러가 필요합니다. 다운로드에는 회사 자료를 포함하지 않는 별도 준비 환경을 사용합니다. 설치 절차가 완료되어도 현재 버전의 업무 입력 제한은 해제되지 않습니다.

## 검증 도구

`tests/test_security.py`는 경로·합성 자료 고정·설치 분리·아카이브·다운로드 주소 제한을 검증합니다. `tests/test_guards.py`는 빌드된 실행기의 실패 폐쇄 동작을 검사하는 도구이며 현재 후보에 대한 통합 실행은 미완료입니다. `scripts/native_probe.py`는 고정된 공개 합성 목적지만 사용하는 네이티브 통신 검사 도구이며 현재 후보에서의 실행·수신측 검증은 미완료입니다.

테스트 결과와 개발 증거는 저장소 밖의 별도 폴더에 보관합니다. 설치 런타임, 모델, 빌드 결과, 비공개 결과, 인증 자료 및 개발 로그를 공개 소스 묶음에 포함하지 않습니다. 공개 출시 전에는 독립 검토와 변경된 Laya 실행 경로의 통신 차단 통합 검증을 완료해야 합니다. 회사의 기존 Claude·GPT Enterprise 사용은 유지하며 PC 전체 인터넷 차단이나 VM 설치를 기본 필수 조건으로 두지 않습니다.
